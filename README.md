Sistema de Gestión de Estudiantes

Primer avance Programación II 

Este proyecto consiste en el desarrollo de un Sistema de Gestión de Estudiantes utilizando C# y Windows Forms en Visual Studio. Su objetivo es facilitar la organización de la información de los estudiantes, sus materias y calificaciones.

Durante este primer avance se diseñó un formulario que permite ingresar los datos de los estudiantes y cuenta con tres botones: Guardar, Limpiar y Salir. Actualmente, Guardar comprueba que la información sea correcta, pero todavía no almacena los datos en SQL Server.

También se creó una base de datos con tres tablas relacionadas: Estudiantes, Materias y Calificaciones. Esta incluye las materias de Ingeniería en Sistemas y algunos datos de prueba.

Para el desarrollo se utilizaron Visual Studio, C#, Windows Forms, SQL Server y SQL Server Management Studio.

El proyecto continuará desarrollándose para incorporar la conexión con la base de datos y las demás funciones previstas.

Se utilizó ChatGPT, de OpenAI, como apoyo para resolver dudas, elaborar y revisar código, y crear la estructura de la base de datos.
